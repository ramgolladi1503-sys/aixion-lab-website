## Locked direction

The approved design is the light, soft-neutral systems family selected on 2026-08-23. It combines the strongest qualities of Soft Neutral Storyteller, Scroll Narrative and Cards & Glass, but the final authority is neither white nor dark.

The site should feel like a calm engineered research environment: soft sage-greige canvas, pale mineral surfaces, editorial typography, restrained system diagrams, evidence-led cards and subtle depth.

## Palette

- Primary canvas: soft sage-greige / mineral mist, target `#E9EDE7`
- Raised surface: `#F2F4EF`
- Cool surface: `#EDF1F2`
- Lavender surface: `#F0EDF3`
- Warm surface: `#F2ECE7`
- Primary text: charcoal mineral `#353A37`
- Secondary text: `#6D756F`
- Sage accent: `#78998B`
- Muted teal: `#76989A`
- Soft blue: `#8199B0`
- Lavender: `#A79CB8`
- Pale peach: `#C8A897`

Do not use pure white as the dominant page background. Do not use black or near-black as a dominant surface. No neon colors, cyberpunk blue, large dark panels or dark-mode sections.

## Typography

1. Editorial serif for hero statements, system names and major headings.
2. Clean grotesk sans for navigation, body copy, controls and cards.
3. Monospace only for evidence, IDs, states, timestamps and traces.

## Layout language

- generous negative space
- thin outlined cards
- very subtle shadows
- soft radii
- precise metadata alignment
- architecture diagrams rather than decorative dashboards
- muted charts
- light status tags
- restrained abstract geometry
- small technical annotations
- no wall of identical SaaS cards

## Page treatments

### Home
Soft sage-greige canvas, editorial hero, abstract architectural still life, Lab Pulse immediately below, featured systems, research and journey previews.

### Systems Registry
Light catalog rows/cards with state, current gate, latest evidence and a subtle system accent.

### TradeBot
Remain light. Use pale technical modules, thin architecture paths, muted blue/sage/lavender data accents and evidence records. Never expose proprietary strategy logic.

### Aixion Control Core
Use a pale orchestration diagram with a softly tinted central Control Core node and surrounding capabilities. Execution traces use monospace without terminal-black styling.

### Automation
Use warm-mineral process diagrams and workflow lanes. Show reliability, failure handling and evidence instead of generic RPA illustrations.

### Analytics
Use pale blue/mineral chart surfaces with restrained visualization colors and strong explanatory copy.

### Research
Allow subtle lavender/mineral accents. Rejected research is visually equal in dignity to validated work; state is communicated by label, not loud color.

### Pulse
Use a light operational board with stage lanes, current focus, latest evidence and next gate. Never show arbitrary completion percentages.

### Journey
Editorial timeline with soft architectural still-life elements and a clear QA → automation → software → data → ML → autonomous systems → Aixion progression.

### About / Career
Human and editorial. Use a portrait only when an approved real image is supplied. Until then, no generated person should represent Ram.

### Contact
Minimal. Soft mineral surface, concise intent choices and direct contact links.

### 404
Quiet, playful architectural composition using the same pale materials.

## Motion

Motion communicates state only. Use subtle route/section fades, Aixion Signal progression, evidence-drawer motion and stage transitions. No scroll hijacking, particle fields, floating cards, sound, replacement cursor or decorative WebGL.
