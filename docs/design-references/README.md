## Implementation comparison rule

Every major visual iteration should be compared against these references before being accepted.

At minimum compare:

1. **Hero/world** — scale, exposure, world richness, aqua/glass clarity, cloud depth, left/right balance.
2. **Systems** — spatial hierarchy, useful context, visual continuity, not generic accordions/cards only.
3. **Evidence** — layered / inspectable visual language, not fake performance metrics.
4. **Principles** — editorial rhythm, controlled density, no generic corporate values layout.
5. **Founder/Journey** — real Ram Golladi narrative only; no generated portrait or credentials unless explicitly supplied and approved.
6. **Contact** — calm horizon/end-state feeling; only real contact methods.
7. **Footer** — minimal; do not duplicate the persistent header navigation. GitHub is the only secondary destination required here.
8. **Sound** — optional, muted by default, clearly audible after an explicit user action, pleasant and unobtrusive.
