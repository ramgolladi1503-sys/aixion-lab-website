# Motion Lab — Scene 3: Applied Systems

## Visual target

The Scene 2 graph spreads into four spatial clusters: Systems, Research, Automation and Analytics. Each cluster grows a fine rectangular frame around its nodes while a small number of edges remain between clusters, so the network reads as one coordinated practice. The forms stay abstract and original; no fake dashboard values, labels inside the renderer, or product screenshots appear. HTML links beside the scene lead to the corresponding existing public routes.

The change is a continuation of the graph's motion: hubs travel outward, member nodes follow, and frames grow from the graph's existing anchor points. Scrolling backward collapses the frames and draws the nodes back to the central engineering graph.

## Constraints

- Reuse Scene 2's graph, nodes, connections and single Canvas.
- Preserve four clear semantic links in HTML with visible keyboard focus.
- Keep the composition responsive; reduce spacing on narrow screens without clipping controls or content.
- Reduced motion and renderer failure still expose all chapter copy and links through native document flow.
